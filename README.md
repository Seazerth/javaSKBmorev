Условие задания

1. Почитать про WebApplicationContext и про маппинги (какие бывают и какие у них параметры).
2. Реализовать два контроллера:

    - Первый контроллер должен обрабатывать GET запрос и отдавать шаблон, в котором выводится список всех заголовков запроса.
    - Второй контроллер должен принимать JSON вида:
      {
      "price": 125.0,
      "info": {
      "date": "2022-01-01"
      }
      }
      и возвращать его обратно, добавляя в ответ свойство `id`:
      {
      "price": 125.0,
      "info": {
      "id": 123,
      "date": "2022-01-01"
      }
      }

3. Написать обработчик ошибок, который будет возвращать кастомную ошибку с кодом 502 (Bad Gateway).
