# Spring Security RolesAllowed Example

**ФИО:** Морев Владислав Витальевич  
**Преподаватель:** Никита Карсканов

## Условие задания

Реализовать Spring Boot приложение с разделением прав доступа с использованием аннотации `@RolesAllowed`.

**API:**
- `GET /public/api` — доступ открыт для всех
- `GET /admin/api` — доступ только для пользователей с ролью `admin`
- `GET /support/api` — доступ только для пользователей с ролью `support`

Приватные эндпоинты возвращают имя и роль авторизованного пользователя.

### Требования:
- Хранение пользователей в памяти (InMemoryUserDetailsManager)
- Basic-аутентификация
- Хеширование паролей с помощью `BCryptPasswordEncoder`
