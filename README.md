## Описание

Реализация микросервисного взаимодействия между двумя Spring Boot приложениями с использованием **RabbitMQ**.

- `Sender` отправляет сообщения в очередь `edu.queue`.
- `Receiver` получает сообщения из этой очереди и выводит их в консоль.

---

## Структура проекта

### Sender-приложение (`education-0.0.1-SNAPSHOT.jar`)
- Порт: `8080`
- Эндпоинт: `POST /send`
- Получает JSON и отправляет его в очередь `edu.queue`
- Использует `RabbitTemplate`

Пример запроса:
```json
{
  "from": "Иван",
  "content": "Привет!"
}


Receiver-приложение (1234-0.0.1-SNAPSHOT.jar)

    Порт: 8081

    Слушает очередь edu.queue

    Выводит полученное сообщение в консоль с помощью @RabbitListener
