Изменения в проекте

Заменил System.out.println() на логирование:
Вся печать сообщений на консоль была заменена на использование логирования с помощью библиотеки Lombok и аннотации @Log4j2.
Это позволяет более гибко управлять логами (например, устанавливать уровни логирования и выводить их в файлы), что является лучшей практикой в производственных приложениях.

Использование Lombok для логирования:
Добавлена аннотация @Log4j2 для автоматической генерации логгера, что упрощает код и улучшает читаемость.

Оптимизация логирования:
Использование {} внутри метода log.info(), что улучшает производительность логирования за счет ленивой подстановки параметров.
