## Условие задания

Необходимо создать Spring Boot приложение для работы со списками дел, в котором:

1. **Создать контроллер с двумя эндпоинтами:**
    - `POST /todos` - принимает JSON-данные в следующем формате и сохраняет их в базу данных:
      ```json
      {
        "name": "Мой список дел",
        "events": ["дело1", "delo2", "delo3"]
      }
      ```
    - `GET /todos` - возвращает все списки дел из базы данных в формате:
      ```json
      [
        {
          "name": "Мой список дел",
          "events": ["дело1", "delo2", "delo3"]
        },
        {
          "name": "Мой список дел2",
          "events": ["дело1", "delo2", "delo3"]
        }
      ]
      ```

2. **Спроектировать структуру базы данных для этих данных.**
    - В качестве базы данных использовать PostgreSQL.

## Технологии
- Java 17
- Spring Boot 3.x
- Spring Data JPA
- PostgreSQL
